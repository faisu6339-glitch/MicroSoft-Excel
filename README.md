Welcome to my **Microsoft Excel — Basic to Advanced** repository!

This repository documents my learning journey and practical exploration of Microsoft Excel, covering essential spreadsheet operations, data cleaning, formulas and functions, data analysis, visualization, PivotTables, dashboards, and advanced Excel techniques.

## 🧩 Example: Sales Analysis Formula

Suppose an Excel table named `Sales` contains `Region` and `Revenue` columns.

To calculate total revenue for the North region:

```excel
=SUMIF(Sales[Region],"North",Sales[Revenue])
```

To count the number of sales records for the North region:

```excel
=COUNTIF(Sales[Region],"North")
```

To calculate revenue for the North region where revenue exceeds 10,000:

```excel
=SUMIFS(Sales[Revenue],Sales[Region],"North",Sales[Revenue],">10000")
```

These examples demonstrate how Excel formulas can transform raw transaction data into useful business metrics.
